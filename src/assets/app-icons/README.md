# 应用图标来源

`picoclaw.png` 原样取自 [PicoClaw 官方仓库](https://github.com/sipeed/picoclaw) 的 Web UI favicon（96×96、透明 PNG），仅在 LVGL 显示时等比缩放。

- 固定提交：`bbf6893ca7afad27f1d00a0f5a45982a549c6ed6`
- [原始文件](https://github.com/sipeed/picoclaw/blob/bbf6893ca7afad27f1d00a0f5a45982a549c6ed6/web/frontend/public/favicon-96x96.png)
- [下载地址](https://raw.githubusercontent.com/sipeed/picoclaw/bbf6893ca7afad27f1d00a0f5a45982a549c6ed6/web/frontend/public/favicon-96x96.png)
- SHA-256：`66727f6b15292b105ffe90e10bf1a1a1ec13c66fed082d594a1522752ec6fc15`
- 上游仓库许可：MIT，保留在 [PICOCLAW-LICENSE.txt](PICOCLAW-LICENSE.txt)。

设置图标使用 LVGL / Montserrat 内置的 `LV_SYMBOL_SETTINGS` 齿轮符号，不依赖外部图片。
