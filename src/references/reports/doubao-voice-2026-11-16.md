# 豆包语音适配与实机验证（2026-11-16）

测试主机日期为 2026-11-16，时区 Asia/Shanghai；开发板通过 `root@192.168.5.156` 连接，ARMv7、Linux 6.1.99，C-Media USB Audio Device。验证范围是 PicoClaw 的豆包语音客户端与既有音频链路，不包含官方桌面版完整人设 / 音色选择界面的移植。

## 实现与配置

增加 `provider: volcengine`，ASR / TTS 可单独选择，缺省继续使用现有自定义服务。豆包使用新版 `X-Api-Key` 鉴权，默认 ASR 资源为 `volc.seedasr.sauc.duration`，TTS 为 `seed-tts-2.0`、Vivi 2.0 音色。ASR 复用 16 kHz 录音，通过 gzip WebSocket 二进制协议流式传输；TTS 通过 HTTP 流式 JSON / Base64 返回 24 kHz PCM，复用原有播放、音量及停止播报路径。

板端保留原有 LLM、音频偏好和其他应用配置，只替换语音配置。新密钥在 `secrets/doubao.key` 和待编辑区均为 `600` 权限；未将密钥值写入源码、文档或日志。通过设置组件的 `system.restart` 业务事件，执行现有快照校验和原子配置切换，随后重启正式监督服务。该流程也验证了豆包配置不再要求参考 WAV。
