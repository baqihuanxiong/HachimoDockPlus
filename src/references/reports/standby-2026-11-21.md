# 显示待机、按键与 Agent 唤醒（2026-11-21）

## 行为

本次实现显示待机，系统、网络及音频服务继续运行，不进入系统深度休眠。

- 设置 → 外观向下滚动，在“自动待机”选择关闭、30 秒、1 / 3 / 5 / 10 分钟；原子保存至界面偏好，默认关闭，兼容缺少新字段的旧文件。
- SW3 按住约 1.5 秒关闭显示，松手不再执行短按。短按在松开时执行，保留屏保、返回、键盘 / 弹层关闭及 NewAPI 取消倒计时等行为。
- 待机中任意实体按键或触摸可唤醒；首次唤醒动作及该实体键的松开均被拦截，不触发原页面操作。待机前已按住的 SW1 仍会向前台应用交付松开，以结束录音。
- 普通唤醒保留原页面或屏保；待机期间暂停桌宠解码。新的有效非空闲 Agent 任务状态可以亮屏并进入桌宠屏保，独立于用户所选时钟 / 纯黑 / 桌宠偏好。原页面保持挂载，退出桌宠后返回原页面。
- 正常亮屏使用时任务不抢占页面；任务持续展示时重置闲置计时，结束展示过期或状态失效后重新计时。手动待机后，同一任务的重复状态不会立即唤醒。探测心跳、空闲、隐藏或过期会话不唤醒。

显示使用 `FBIOBLANK` 的 `FB_BLANK_POWERDOWN` / `FB_BLANK_UNBLANK`，通过真实 DRM 状态验证，不依赖此 SDK 返回空内容的 `fb0/blank` 读接口。启动及正常退出时尝试恢复输出。失败不提交待机状态，自动重试有间隔，页面可继续使用；错误写入运行日志。

## 主机检查

- 待机控制器 race 测试：禁用计时、活动重置、按住按键、长短按边界、SW3 松开、各键唤醒及释放拦截、新任务与重复任务、设备失败及重试、录音键释放。
- 偏好与设置应用 race 测试：旧文件迁移、时长校验、保存恢复、设置事件与失败状态。
- 桌宠状态 race 测试：会话身份与转换版本、旧转换过滤、隐藏队列和失效状态。
- Go LVGL 适配器 race 测试通过；native 和 ARM 构建通过；相关包 `go vet` 及差异空白检查通过。
- 完整原生 UI 检查通过。新增断言覆盖待机下拉框滚动、选项及事件，屏保恢复原设置页，真实 LVGL 指针输入的唤醒触摸及释放不穿透至下层标签页；音乐、NewAPI、PicoClaw 等既有检查继续通过。

## 板端检查

Lyra Zero W / RK3506B，Linux 6.1.99，WLK2802MIPI / ST7701S。先独立短时关闭显示，确认 DRM VOP 从 `ACTIVE` 变为 `DISABLED`，恢复后回到 `ACTIVE`，正式服务没有退出。

候选版验收停止正式服务，使用独立的临时配置、内存数据目录与临时 LAN 配对，继续使用现有素材；不覆盖用户配对。测试通过认证的真实 TCP / AES-GCM 会话推送状态。

| 场景 | 证据与结果 |
|---|---|
| 30 秒无操作 | VOP 进入 `DISABLED`，SSH / LAN 仍可用 |
| 心跳、空闲、隐藏工作会话 | 显示保持关闭 |
| 触摸唤醒 | VOP 恢复 `ACTIVE`，仍为原 Wi-Fi 页；触摸位置的系统页签未被激活 |
| 有效工作任务 | 恢复 `ACTIVE`，时钟偏好下仍显示“小新 · 已连接 · 工作中”和测试任务内容 |
| 持续工作超过 30 秒 | 持续推送下保持显示，桌宠解码进程为 1 |
| 任务转空闲后 30 秒 | 再次进入 `DISABLED`，桌宠解码进程归零 |
| 清理与恢复 | 临时进程、配置、数据及测试配对清理；恢复正式服务 |

首轮完整长流程触发执行环境时限，已手动恢复正式服务并核对用户文件；随后拆分，以最终候选完成任务唤醒、任务结束再待机及自动清理闭环。没有把中断当作通过。

实体 SW3 长按及各实体键实际唤醒需人工实按确认；目前输入策略通过可控事件测试。背光是否完全熄灭也需实屏观察，DRM 关闭不等于已经完成背光光度验收。本次未做音频持续播放或功耗测量。
