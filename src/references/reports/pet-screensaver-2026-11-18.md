# 桌宠屏保与 LAN 展示协议验证（2026-11-18）

## 基线与变更

Lyra Zero W / RK3506B、ARMv7 hard-float、现有 Linux 6.1.99 / Buildroot，横屏 640×480，LVGL v9.3.0。板端 FFmpeg 4.4.4。上游参考固定到 `165401b3e2b1333022e8f0fdddcbebc14d669dba`。

新增公共桌宠屏保、离线 MP4 包准备工具、SMB 候选资源校验，以及官方 Desktop LAN 展示接收服务。视频后台软件解码，只有屏保可见时播放，不打开音频。网络只开放发现、自动配对、探测、状态查询与快照，不实现 USB、素材下发、远程控制或组件生态。

## 自动与离屏检查

- 全量 `go test -race -p 2 -tags stdjson,goolm ./...`、`go vet` 通过；之后新增配置路径用例的相关包测试通过。
- native / ARM 构建及现有全部 LVGL 原生 UI 检查通过。原生测试增加桌宠像素颜色、文字和三次创建 / 释放检查。
- 真实 FFmpeg 测试验证短片循环、BGRA 帧颜色、取消退出和无效文件错误；保持有界帧缓冲。
- LAN 集成测试覆盖 UDP 随机数发现、错误 SRP 证明拒绝、成功配对、GCM 篡改拒绝、快照、配对持久化、解除配对及半包连接取消。
- 会话测试覆盖选中会话优先、相同终态不续期、旧修订拒绝、来源切换及探测不能续期过期内容。
- 离线工具从上游准备 16 段西高地动画，转换后约 5.9 MiB，保留 LICENSE 和来源。native 屏保预览可见动画帧。

## 实机结果

先在 `/tmp` 中以独立测试配置运行新程序，停止已有 UI，使用真实帧缓冲和经身份校验的 evdev 注入验证：

- 西高地待机和不同动画帧可见。
- 独立 Python 协议客户端完成自动 SRP 配对、状态读取、认证标签篡改拒绝，以及工作 / 等待确认 / 完成 / 错误会话的发送与画面检查。
- 停发超过 10 秒后旧任务文字清除，动画回到待机；触摸唤醒返回目录，FFmpeg 进程退出。
- 一次约 5.17 秒的工作动画采样：UI 约 87.4%、解码进程约 60.5%（均按单 CPU 核 100% 计）；RSS 分别约 35.8 / 11.8 MiB。这是一次实际负载采样，不是所有素材的性能保证，也不是实屏 FPS 测量。

开发机与开发板不同子网，直连发现请求被同子网规则拒绝。板端 UDP 发现通过回环验证；板端配对与加密快照通过 SSH TCP 转发运行独立 Python 客户端验证。未放宽子网规则。**这不是官方 Desktop GUI、真实 Agent、同网段 Wi-Fi 的端到端验收。**
