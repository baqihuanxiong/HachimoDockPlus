## 故障、复测与交付

- 原参考地址 `192.168.4.202` 不可达；用户更新为 `192.168.5.156` 后连接、部署与验证通过。
- 原文件的模型 API Key 被管理接口拒绝；改用用户补充的管理员 Access Key 后只读查询通过。
- MiMo 采用用户提供的新查询地址，并用 LLM 小节中的实际 Key 验证；不需要 Cookie。旧控制台 Cookie 方案未进入最终实现。
- 空间不足风险通过清理未使用的旧程序版本解决，按 `--no-backup` 部署后仅保留最终版本；保留配置、密钥与数据。
- 最终二进制重新部署后再次完成隔离板端取消、提前执行和自动执行验证，随后恢复正式监督服务。重置验证从未接通真实用户余额。
- 恢复后再次用最终产物查询正式网关与 MiMo，截图为 `final-live-overview.png`、`final-live-provider.png`；监督服务正常，板端仅有正式配置的一个 UI 进程，发布目录与完整哈希核对一致。
- 未使用调试端口或生产页面测试按钮；保留正式 Go / C 回归测试及合成网关夹具。图标为字母 `N`，沿用既有共享字体许可，无新增第三方图像。
- 后续需要补齐：阿里真实账户查询、人工物理 SW2 / SW3、人工面板与实屏性能观察；真实用户批量重置应由用户在明确选择的运行窗口操作。
