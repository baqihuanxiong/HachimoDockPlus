# 设置与公共界面

组件 ID 为 `settings`，包含 Wi-Fi、蓝牙、外观与系统页。进入后读取状态，前台每 5 秒刷新；离开取消请求与扫描，再次进入重新读取。没有相应硬件或服务时显示不可用信息，其他组件仍可使用。

## 组件中心与输入

目录每页两列、两行，左右滑动整页切换，底部圆点可跳页。点击整张卡片均可打开，拖动卡片不会误触打开。排列由 `ui.app_order` 决定，规则见 [组件排序配置](configuration-sharing.md#组件排列顺序)；卡片图标及后台徽标的开发约定见 [应用开发规范](app-development.md#后台状态与卡片分页)。

| 输入 | 公共行为 |
|---|---|
| 摇杆四方向 | 目录中移动选中框，左右跨页时保持所在行 |
| SW2 | 目录中打开选中组件；组件内的主操作由对应页面定义 |
| SW3 短按后松开 | 目录中进入屏保；屏保中返回原页面；组件内先执行页面短按操作或关闭弹层 / 键盘，再返回 |
| SW3 长按约 1.5 秒 | 关闭显示进入待机；松手不会再执行短按动作 |
| SW1 | 由组件定义，目前用于 PicoClaw 按住录音和停止回复 |
| 摇杆按下 | 当前未绑定动作 |

触屏翻页后选中该页首个组件。预览与终端模式不申请物理输入。底板轴方向、去抖、校准及设备互斥见 [输入硬件约定](hardware-adaptation.md#按键摇杆和资源所有权)；当前底板需设置 `ui.controls.invert_y: true`，开发机可用 `ui.controls.disabled: true` 禁用硬件输入。

## 外观与状态栏

外观页提供九种主题色、独立的白天 / 黑夜模式，以及时钟 / 纯黑 / 桌宠屏保。选择立即生效，原子保存到 `data_dir/preferences.json`（权限 `600`），重启恢复。旧偏好缺少模式或屏保字段时分别使用黑夜模式、时钟屏保。桌宠的离线素材导入、Desktop Wi-Fi 配对和播放限制见[桌宠屏保](pet-screensaver.md)。

当前设备尚无已验证可用的背光调节链路，外观页不提供亮度控件。2026-11-21 实机检查：`simple-panel-dsi` 自动注册的 DCS 背光节点可保存亮度设定值，但写入 255、192、128 时 `actual_brightness` 始终返回 0；没有背光 PWM，已注册的 PWM 用于 CPU 供电。这不能证明 DCS 命令实际改变了屏幕亮度，也不能据此断言面板硬件永远无法调光。检测后已恢复设定值 255，未改动内核、设备树或接线。

屏保在目录短按 SW3 进入。桌宠模式触摸用于互动，短按 SW3 返回原页面；时钟和纯黑模式触摸或短按 SW3 返回。摇杆不退出屏保；纯黑屏保不关闭背光。时钟和桌宠右上角时间使用 `ui.timezone`（默认 `Asia/Shanghai`），桌宠仅显示时分（`HH:MM`），未对时时显示“等待对时”。

外观页向下滚动可设置“自动待机”：关闭、30 秒、1 / 3 / 5 / 10 分钟。通过 `preferences.json` 的 `standby_seconds` 保存，默认 0（关闭），旧偏好同样默认关闭。触摸、拖动、按键与摇杆操作会重置计时，按住触屏或实体按键期间不自动待机。任何页面均可长按 SW3 约 1.5 秒手动待机。

待机通过 framebuffer `FBIOBLANK` 关闭显示输出，保留系统、Wi-Fi、音频与前台应用；暂停桌宠解码。任意按键或触摸恢复原页面，唤醒动作本身不操作页面。收到已配对上位机的新有效非空闲 Agent 任务状态后自动亮屏进入桌宠屏保，即使屏保偏好为时钟或纯黑；短按 SW3 可返回原页面。正常亮屏时任务推送不抢占页面。有效任务展示期间暂停闲置计时，任务结束展示过期或上位机状态失效后按所选时长重新计时；手动待机不会被同一任务的重复推送立即撤销。探测心跳、空闲与隐藏会话不触发任务唤醒。

实机已验证显示控制器关闭 / 恢复通路；背光是否完全熄灭仍需实屏观察确认。这不是整机深度休眠，不写入 `/sys/power/state`。

进入屏保使用约 180 毫秒的淡入，缓和组件中心到屏保的直接切换；动画期间也可立即唤醒。该过渡不改变帧缓冲同步方式，不能据此认定物理屏幕撕裂已消除。

首页单行顶部栏显示标题、月日 / 星期 / 时间及无线、电池图标。Wi-Fi 图标反映本机关联和信号强度，不代表互联网可达；蓝牙只在有已连接设备时显示，优先显示音频设备类型。电池是电压粗估，失败时为灰色未知图标，不显示百分比。状态由共享监视器后台采集，详见 [硬件基线](hardware-adaptation.md)。

## Wi-Fi 与蓝牙

| 能力 | 行为与限制 |
|---|---|
| Wi-Fi | 扫描、手动添加、连接、断开、忘记与已保存网络重连；支持 WPA/WPA2 Personal 和开放热点，不支持纯 WPA3、企业 EAP 或 WEP |
| Wi-Fi 保存 | 连接取得 IP 后才保存；失败或取消尝试恢复原网络。忘记立即删除保存项，断开只影响本次运行 |
| 蓝牙 | 电源开关、扫描、配对、连接、断开和移除；`NoInputNoOutput` 配对代理，不支持输入 PIN 或数字确认 |
| 蓝牙扫描 | 首轮读取约 15 秒，发现会话在设置页内继续持有，离开后取消并回收；设备列表最多 24 项 |
| 蓝牙音频 | 配对后在系统页选择输出；需 BlueALSA，实际发声与 Wi-Fi 共存仍待验收，见 [板级模式限制](../../board/lyra-zero-w/wifi.md#经典蓝牙音频与默认-ble-模式) |

Wi-Fi 复用系统 wpa_supplicant、DHCP 和持久化配置，不另起守护进程。保存需要 `update_config=1` 和可写配置；密码不进入命令行、日志或状态快照。蓝牙配对记录由 BlueZ 保存，电源状态遵循系统重启策略。名称、缓存、发现会话及音频服务细节见 [系统配置说明](configuration-sharing.md#资源文件与音频输出)。

## 系统管理与诊断

系统页提供共享账号、SMB 开关、应用配置并重启，以及全局音量和内置扬声器 / S/PDIF / 蓝牙输出选择。安装、持久化、配置校验与生效规则统一见 [SMB 配置共享](configuration-sharing.md)。

系统页底部为 Desktop Wi-Fi 配对区，显示配对状态，并在已配对且没有操作执行时启用“解除配对”。屏保模式仍在外观页选择。

在 `src/` 运行 `tools/dev.sh build/native/dock -config .local/config.json -ui terminal -page settings` 可进行终端诊断，命令包括 `/scan`、`/bt-scan` 和 `/event wifi.connect 0`。真实无线操作需在具备相应系统服务的设备上执行；UI、取消、重入与资源释放按 [实机测试流程](board-validation.md) 验证。
