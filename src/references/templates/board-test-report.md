# 应用组件实机测试报告

复制本模板至自己的记录目录；开发原始证据可放 `src/build/reports/<组件>-<日期>/`。只有脱敏后的总结进入仓库；下列空项不代表已验证。

## 基本信息

| 项目 | 本轮记录 |
|---|---|
| 组件 ID / 功能范围 | 待填写 |
| 测试人员 / 主机日期、时区 | 待填写，区分板端未对时日期 |
| 开发板 / 接线 / 固件、内核 | 待填写 |
| 主机 Git 提交 / 工作区变更摘要 | 待填写，包括相关新增文件 |
| 本机构建产物 SHA-256 | 待填写 |
| 板端产物 SHA-256 / `current` | 待填写，与本机比对 |
| 配置结构 / 数据集规模 | 仅记非敏感项，注明真实或模拟服务 |
| 测试前服务、音量、登录及连接状态 | 待填写 |
| 测试后恢复情况 | 待填写 |

## 故障与复测

- 最小复现、失败产物哈希与证据：待填写。
- 定位层级、依据和修复内容：待填写。
- 同一失败用例的复测版本、证据与结论：待填写。
- 受影响邻近用例的回归结果：待填写。
- 仍存在的外部服务、硬件或其他限制：待填写；没有证据时不推断为已修复。
