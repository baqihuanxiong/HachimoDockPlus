# 网易云音乐

应用 ID 为 `music`，在 `bootstrap/apps.go` 注册，按需初始化。使用中国大陆手机号（+86）和短信验证码登录，已删除扫码流程及相关接口。短信发送成功后倒计时 60 秒，返回后重新进入也保留剩余间隔；手机号与验证码仅用于本次请求，提交后清空验证码输入框。成功登录后只保存权限为 `600` 的 Cookie 文件，重新打开应用自动检查并恢复登录。

## 播放操作

| 输入 | 行为 |
|---|---|
| SW2 / 播放按钮 | 播放或暂停，没有选歌时从当前歌单第一首开始 |
| 摇杆物理左 / 右 | 上一首 / 下一首，首尾循环 |
| 摇杆物理上 / 下 | 全局音量增加 / 减少 5%，长拨继续调整，无需打开音量条 |
| 音量图标 | 弹出全局音量条；点击外部或按 SW3 关闭 |
| 拖动进度条 | 预览目标时间，释放后实际跳转，暂停状态保持 |
| 唱盘 / 歌词 | 点击在带封面的唱盘和歌词之间切换 |
| 歌单 | 选择自己的歌单，点击歌曲播放；歌曲每页 20 首 |
| SW3 | 先关闭键盘、音量弹层或歌单列表，再返回组件中心并停止播放 |

物理向上在当前底板和既有目录校准中产生正 Y（`controls.Down`），音乐应用据此映射为增加音量；不改变组件中心的导航配置。

歌单名显式按主题设置文字颜色、取消按钮默认内边距，并固定为左对齐；选中行使用强调色及白字，未选中行使用主题正文颜色。应用卡片使用铺满容器的红底网易云音乐图标，由容器统一裁切圆角。

## 封面与歌词

歌单详情读取完整 trackIds，按 200 首批次解析歌曲，保持歌单顺序并取得专辑封面地址。切歌时音频、封面和歌词各自异步加载；取消或离开后的迟到结果不会覆盖新歌曲。

封面只从网易云图片域名以 HTTPS 读取，请求 256×256 缩略图，限制编码大小 2 MiB、原始尺寸不超过 2048×2048。Go 解码 JPEG / PNG、居中裁切为 192×192，再将不可变 BGRA 像素快照交给 UI 线程；LVGL 负责圆形裁切、缓存及释放。

LRC 歌词支持一行多个时间戳、毫秒精度、offset 标签及按时间排序，界面显示前一行、当前行、下一行，随播放进度和拖动跳转更新。无歌词显示“暂无歌词”，图片读取失败则使用默认音乐图标，不中断播放。暂未提供逐字歌词、翻译歌词或手动滚动歌词。

## 流式音频及跳转

当前板载 FFmpeg 不支持 TLS。每次播放由 Go 创建仅绑定 `127.0.0.1` 的临时 HTTP 桥，使用随机路径，把请求转发到网易云签发的 HTTPS 地址。桥接保留 GET / HEAD、Range / If-Range 以及 Content-Range / Content-Length 等响应信息，使 FFmpeg 的输入定位可请求目标字节范围；解码后的 PCM16 / 48 kHz / 双声道通过有限缓冲管道交给 aplay。

拖动只在释放时提交一次跳转。应用取消并回收上次播放，以目标秒数重建解码，保留暂停状态，封面和歌词继续复用。首次缓冲与定位需要少量时间，进度按本地播放时间估算；试听片段不开放跳转，会员和版权限制遵循服务端权限。退出会取消请求、关闭临时桥、回收 FFmpeg / aplay 并关闭功放，无整首文件落盘。

## 全局音量和凭据

- `data_dir/volume.json`：音乐与 PicoClaw 共用的音量，原子保存，重启恢复。
- `data_dir/apps/music/session.json`：登录 Cookie，权限 `600`，不进入日志或状态快照；退出账号删除。
- 0% 关闭播放开关静音；默认 60% 对应 CM108B `17,17`（−20 dB），100% 限制为已试听的 `29,29`（−8 dB）。

`audio.mixer_card` 默认 `Device`；`audio.playback_device` 指定 ALSA PCM 设备。音乐和语音共用输出锁和功放控制，其他声卡的混音器名称与增益需单独适配。

接口依据 [NeteaseCloudMusicApiEnhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced) 的定义实现；短信登录仍可能被网易云要求额外验证，页面会按实际结果提示，不自动重复发送。当前不支持搜索、下载、音质选择或版权解锁。

在 `src/` 执行：

```sh
tools/dev.sh go test -race -p 2 -tags stdjson,goolm ./...
tools/dev.sh go vet -tags stdjson,goolm ./...
tools/dev.sh tools/build.sh native
tools/dev.sh tools/check-ui.sh
tools/dev.sh tools/build.sh arm
```

Go 测试覆盖短信登录与恢复、完整歌单顺序、封面解码限制、LRC 解析、暂停后跳转、快照副本、取消与迟到结果、音量保存及回环桥 Range 转发和关闭。实际子进程测试验证暂停、继续及暂停中取消。LVGL 原生测试覆盖双主题歌单文字及左边距、封面释放、歌词切换、拖动期间进度不被刷新覆盖、释放后跳转事件、音量弹层和短信键盘；预览位于 `build/native/music-*.ppm`。
